# Security Policy

## Reporting
Please report security issues privately through GitHub's security reporting features when available. Do not publish real credentials or personal data in an issue.

## Scope and design
Privacy Audit is a read-only local heuristic scanner. It does not upload files, make network requests, follow symbolic links, delete content, or claim that a clean scan proves a file is safe. Findings can contain sensitive context, so generated output should be handled as sensitive data.

## Supported version
Security fixes target the latest release on `main`.

# Privacy Audit — الدليل العربي

**Privacy Audit** أداة Python محلية وخفيفة لفحص الملفات النصية ومجلدات الشيفرة بحثًا عن أنماط قد تشير إلى معلومات حساسة أو بيانات اعتماد قبل مشاركة الملفات أو نشر المستودع.

الأداة للقراءة فقط، ولا تعدّل الملفات، وتعرض نتائج مختصرة ومخفية جزئيًا لتسهيل المراجعة البشرية أو استخدامها كحاجز بسيط داخل CI.

> الإصدار الحالي: **1.0.0** · يتطلب **Python 3.10+** · الترخيص **MIT**

## التثبيت

</div>

```bash
git clone https://github.com/rad03i2/privacy-audit.git
cd privacy-audit
python -m pip install .
```

## الاستخدام الأساسي

</div>


</div>

</div>

</div>

```bash

```

</div>

```bash

```

ويمكن تشغيل الأداة كـ Python module أيضًا:

</div>

```bash
python -m privacy_audit ./project
```

## القواعد الموجودة حاليًا

| القاعدة | الخطورة | ما الذي تشير إليه |
|---|---|---|
| `email` | منخفضة | عنوان بريد إلكتروني محتمل |
| `ipv4` | منخفضة | عنوان IPv4 |
| `generic-secret` | متوسطة | قيمة تشبه بيانات اعتماد مرتبطة بحقل مثل API key أو secret أو token أو password |
| `private-key` | عالية | رأس مفتاح خاص |
| `aws-access-key` | عالية | معرّف مفتاح وصول بنمط AWS |
| `github-token` | عالية | نمط Token خاص بـ GitHub |

هذه القواعد **استدلالية** وليست إثباتًا. يجب مراجعة النتيجة قبل اعتبارها سرًا حقيقيًا أو بيانات شخصية فعلية.

## طريقة عرض النتائج

النتيجة النصية تعرض:

- مستوى الخطورة؛
- مسار الملف؛
- رقم السطر؛
- اسم القاعدة؛
- وصفًا مختصرًا؛
- مقتطفًا قصيرًا ومخفيًا جزئيًا.

أما وضع JSON فيعرض ملخص الفحص وقائمة النتائج بشكل مناسب للأتمتة.

## رموز الخروج

| الرمز | المعنى |
|---:|---|
| `0` | اكتمل الفحص ولم يتم بلوغ حد الفشل |
| `1` | مسار غير صالح أو مشكلة مرتبطة بالقراءة |
| `2` | تم بلوغ مستوى `--fail-on` المحدد |

## التعامل مع الملفات

الأداة:

- تفحص ملفًا واحدًا أو مجلدًا تكراريًا؛
- لا تتبع الروابط الرمزية؛
- تتجاهل مجلدات بناء واعتماد شائعة؛
- تتجاوز الملفات الأكبر من الحد المحدد؛
- تتجاوز الملفات التي تبدو ثنائية عند وجود NUL byte قرب البداية؛
- تفك النص باستخدام `utf-8-sig`؛
- تتجاوز الملفات غير القابلة للفك بهذه الصيغة.

الحد الافتراضي لحجم الملف هو **2,000,000 بايت**.

## نموذج الخصوصية

Privacy Audit مصمم لإبقاء المحتوى المفحوص محليًا.

لا توجد حزم تشغيل خارجية، والكود الحالي لا ينفذ طلبات شبكة، ولا يعدّل الملفات المفحوصة، ولا يحفظ محتواها عمدًا.

مع ذلك، **تقرير النتائج نفسه قد يكون حساسًا**، لأن المسار ورقم السطر ونوع القاعدة والمقتطف المخفي جزئيًا قد تكشف معلومات مفيدة عن المشروع. لذلك ينبغي التعامل مع تقارير الفحص بحذر.

راجع [SECURITY.md](SECURITY.md).

## الحدود الحالية

Privacy Audit ليست منصة DLP، ولا مدير أسرار، ولا ماسح برمجيات خبيثة، ولا نظام إثبات امتثال أو شهادة خصوصية.

قد توجد نتائج إيجابية خاطئة أو سلبية خاطئة. ولا يفحص الإصدار الحالي الأرشيفات أو الصور أو PDF كمستند منظم أو ملفات Office أو Git history أو الخدمات البعيدة.

النتيجة الخالية من findings **لا تثبت** أن المشروع خالٍ من جميع البيانات الشخصية أو الأسرار.

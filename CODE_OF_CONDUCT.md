# Code of Conduct

## Expected behavior

Project discussions should remain professional, specific, and respectful.

Good participation includes:

- focusing feedback on code, behavior, tests, and documentation;
- giving actionable technical criticism;
- respecting different experience levels;
- avoiding harassment, discrimination, threats, or deliberate disruption;
- protecting sensitive information during debugging.

## Privacy-specific expectation

Privacy Audit exists to reduce accidental exposure. Do not ask contributors to publish real credentials, private files, personal identifiers, or production data when a synthetic reproduction is sufficient.

If sensitive information is accidentally posted, avoid quoting or redistributing it and use the appropriate GitHub reporting/removal path.

## Enforcement

Maintainers may edit, remove, or reject content that violates these expectations and may restrict participation when necessary to keep collaboration safe and constructive.
